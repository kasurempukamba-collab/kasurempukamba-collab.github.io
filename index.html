# about

Exploring systems. Building automation.

I’m Sigma, an independent penetration tester and automation developer. I like digging deep into systems, exploring how they work, and uncovering weaknesses that might otherwise go unnoticed. I also build custom automation scripts to simplify repetitive tasks and make the testing process more efficient.

My penetration testing skills are built on curiosity, continuous practice, and hands-on experimentation rather than predefined client briefs. I learn by putting concepts into practice, developing custom scripts and tools along the way, and refining them until they produce meaningful results. I value practical outcomes over unnecessary complexity. Code is only valuable when it serves a purpose.
